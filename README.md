# SecDevias Frontend/Torii

Código-fonte referente à aplicação web incluindo:
- Cadastro de usuário,
- Login/Logout de usuário,
- Submissão de projeto (por zip, Github ou Gitlab),
- Acesso a relatórios,
- Estatísticas de projetos submetidos,
- Dashboard de projeto,
- Ressubmissão de projetos Github e Gitlab,
- Exclusão de projetos submetidos.
